# Inbound Freight Door Dashboard

A single-file browser dashboard for tracking second-shift inbound freight production across doors 166, 167, 168, 169, 170, 171, 174, 175, and 176.

The dashboard records SOS, P1, P2, and EOS readings; cases, pallets, errors, cases per hour, associates, and checkpoint notes are saved locally in the browser.

## Run locally

Open `outputs/freight-door-dashboard.html` in a modern browser.

No build step or server is required. Dashboard data remains in that browser's local storage.
